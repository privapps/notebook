Start with a blank notebook and write your notes in the browser. Save or publish your current work first: starting over replaces the notes open in this tab. New notes are not saved automatically.

Open a notebook file from your device, or download a copy of your current notebook for backup. Your notebook is not uploaded to a server. Save a new copy whenever you want to keep your latest changes.

  • Load

    Choose a notebook file saved by this app. If you saved it with an E2E key, enter the same key in the E2E Key field before loading it.
  • Legacy

    Use the older file format when needed. With an E2E key, the notebook is encrypted and its symmetric key is stored inside the file. Without an E2E key, this option saves plain text.
  • Save

    Download an encrypted notebook file. An E2E key adds password-based protection and is recommended for sensitive notes. Keep the file name unchanged: it contains the symmetric key needed to reopen the notebook.

Share a snapshot of your notebook through PrivateBin. Publishing creates a new copy rather than updating an existing link. The host's expiration settings determine how long it remains available, so keep a file backup if you need it later.

Put an encrypted snapshot of your notebook directly in shareable URLs, with no notebook server storing the content. Generate both a Notebook Web URL and a compact, read-only Notebook Lite URL from the same snapshot, then copy the one you want to share. After editing, generate both again to include your changes.

Best for small notebooks: long URLs may exceed browser or messaging limits. Keep the link private, and add an E2E key for password-based protection. Anyone with the complete link can open the notebook if no E2E key is set.
